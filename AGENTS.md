# Repository Instructions

- This repo is the record of the agent skills I use.
- `skills.json` pins every installed skill to its source and commit. Keep it matching what is installed.
- Install only from `skills.json`.
- Pin only reviewed versions at least three days old.
- My own skills: one directory each, each with a `README.md` section.
- Third-party skills: never commit unmodified copies. A modified copy goes under `<source>/<skill>/` with the source's licence and a `CHANGES.md`.
- No dependency folders or generated output.
